# THADATHIL Family Hub (v3)

Family management web app made with plain HTML + CSS + JavaScript. Created by Aparna Mohan.

## Run
Unzip and double-click `index.html`. No install or server needed (internet only for Google Fonts: Young Serif and Figtree).

## Structure
- `index.html`  all pages, forms and dialogs as real HTML markup
- `css/style.css`  "Backwater" design system (green, marigold, chilli red), dark mode, family tree, responsive and print styles
- `js/app.js`  data (localStorage), list rendering, family tree, poster drawing

## Pages
Home (hero with banner or pookalam, setup checklist, quick numbers, next meetup, coming-up birthdays, committee, fund, family) · Family (5-generation tree per branch, members, full profile with auto grandparents)
· Committee (current + previous) · Meetups · Programs (programs, games, prizes, gifts) · Finance
· Celebrations · Gallery (Google Drive links) · Posters (meetup, birthday, anniversary + PNG download)

## Tips
- Add the eldest members first, then children by choosing father and mother: the tree builds itself.
- Logo: Family > Edit family & logo. Banner: Home > Change banner.
- Data is stored in this browser only. Poster download works when you open the unzipped files.
